A Mental Model for Pointers
    More mathematically minded readers might view pointers as addresses.
    A pointer is a level of indirection that says to the program, “Hey! Look over there.”
    When you dereference a pointer, by using the * operator, you are telling the program to look one level deeper in memory.
    When you take the address of a location, using the & operator, you are adding a level of indirection in memory.
